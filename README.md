# BioCraft Central — Standalone Admin Dashboard

لوحة تحكم الأدمن المستقلة والمشفرة للتحكم عن بُعد في منصة توليد مواقع البطاقات الرقمية الشخصية عبر قاعدة بيانات Supabase.

## الميزات:
- **حماية كاملة (Supabase Auth Gate):** شاشة تسجيل دخول مشفرة تمنع عرض أي بيانات قبل المصادقة.
- **منع الأرشفة:** ترويسات `noindex, nofollow` لضمان خصوصية وسرية اللوحة.
- **مؤشرات أداء KPI:** إجمالي المواقع، الزيارات الكلية، المواقع النشطة/الموقوفة، والموثقة.
- **رسوم بيانية تفاعلية (Chart.js):** أكثر 10 مواقع زيارة وتوجه النمو خلال آخر 7 أيام.
- **إدارة كاملة للمواقع:** بحث فوري، فلاتر، تفعيل/إيقاف بنقرة، منح شارة التوثيق الزرقاء، تعديل البيانات، وحذف نهائي.
- **تحكم عام بالمنصة:** وضع الصيانة، إيقاف/تفعيل التسجيل، وشريط الإعلانات العام.
- **نسخ احتياطي:** تصدير فوري لبيانات المنصة بصيغتي JSON و CSV.
- **تصميم فخم وأداء عالي:** بدون إيموجي (Zero Emojis)، إطارات زجاجية رفيعة 1px، ودعم كامل للغة العربية.
